# Koreyaki Restaurant Website

A responsive single-page restaurant website using the supplied Three.js scroll-driven noodle animation, styled in red, black and grey.

## Run locally
1. Open `index.html` in a modern browser, or use VS Code Live Server.
2. Internet access is needed for the Google Font and Three.js CDN.
3. Reservation form opens WhatsApp with the guest's details prefilled for Koreyaki (+91 95918 11065). It does not submit to a server or store personal information.

## Customisation
- Edit restaurant copy, menu items, address and contact details in `index.html`.
- The 3D noodle animation uses Three.js from a CDN.
